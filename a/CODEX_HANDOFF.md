# 梗战争模拟器交接记录

- 阶段：Prototype
- 玩家结果：在预算内买兵并部署，开战后观看多波自动战斗；波次无缝衔接，不再有战后整备或中途操作，清空整关后进入结算并可前往下一关，用剩余预算获得 S/D 等级。
- 当前状态：原生 WebGL2 可玩切片已接入《How Many Dudes?》式连续波次自动战斗节奏，并按需求收敛为纯排兵布阵流程；6 关、数据驱动兵种、部署/撤回、拖拽、自动战斗、技能、连续波次、镜头、暂停/倍速和结算已经接通。
- 重要文件：`src/main.js`、`src/sim.js`、`src/webgl.js`、`data/units.json`、`data/levels.json`、`scripts/check-data.mjs`、`scripts/server.mjs`、`scripts/launch.mjs`、`PLAY_GAME.cmd`。
- 验证：`npm run check` 通过；真实浏览器已验证第 1 关“部署 → 第 1 波自动战斗 → 第 2 波无缝入场 → 胜利结算”，过程没有整备弹窗；固定模拟烟测确认 6 关均存在预算内可通关编队；`PLAY_GAME.cmd` 已实测启动服务器并打开页面。
- 当前风险：波次敌群与各单位数值仍是原型平衡；完整 roguelike 商店、遗物池、持久进度和大规模敌群尚未实现；WebGL2 不可用时只有提示，没有 Canvas 2D 降级；正式美术/音频、移动端设备证据尚未纳入；双击入口要求本机已安装 Node.js 18+。
- 下一项最安全任务：用固定种子批量跑 6 关，记录每波存活数与通关率，再调整波次敌群规模和单位数值。
