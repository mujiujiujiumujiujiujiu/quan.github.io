# 梗战争模拟器

一个零依赖、原生 WebGL2 的俯视角梗战争自动战斗原型。战斗结构参考《How Many Dudes?》的“构筑队伍、连续敌群、自动模拟”节奏；玩家只负责预算与布阵，单位会自动寻敌、攻击、释放技能。

## 运行

最简单的方式：双击项目根目录里的 `PLAY_GAME.cmd`，它会自动启动服务并打开系统默认浏览器。

```powershell
cd "C:\Program Files (x86)\Steam\s\steamapps\common\Blender\meme-war-sim"
npm run check
npm run start
```

手动启动后打开 `http://127.0.0.1:4173`。启动脚本使用 Node.js 内置 HTTP 服务，不需要 Python。项目不依赖 Pixi、Three、Matter 或远程 CDN：画面由 WebGL2 着色器直接绘制，战斗碰撞使用项目内的轻量圆形刚体解算，方便离线运行和继续扩展。

## 操作

- 准备阶段：点击底部兵种卡，再点击战场左半区部署。
- 右键玩家单位：撤回并返还费用；拖拽可调整位置。
- `开始战斗`：锁定部署并观看自动战斗。
- 每清空一波下一波立即入场；清空全部波次后进入结算并可前往下一关。
- 战斗阶段：空格暂停；`1 / 2 / 4` 切换倍速；按住 `G` 或鼠标左键进入慢动作。
- 鼠标拖拽平移镜头，滚轮缩放。
- 右上角可切换 6 个关卡，`再来一次` 会保留当前关卡并清空部署。

## 当前切片

- 6 个数据驱动关卡，12 个可部署梗单位 + 1 个路障 + 敌方专属瓜摊老板。
- 预算、费用、部署区限制、撤回退款、敌我存活计数。
- 6 个关卡都拆成多波敌群；单位会带着当前生命状态连续作战，清空全部波次后才算通关。
- 最近目标 / 远程优先、近战与远程攻击、投射物、击退、眩晕、减速、嘲讽、治疗、冲锋、AOE、召唤和延迟标记。
- 单位头顶血条、技能/命中/治疗/死亡特效、事件播报、战斗倍速和结算评级。
- 13 个原创水彩墨线角色头像；远程、召唤和辅助单位会保持安全距离，敌人贴近时主动后撤。

## 目录

- `index.html`：页面结构与 UI 入口。
- `src/webgl.js`：原生 WebGL2 渲染器、相机投影和战场绘制。
- `src/sim.js`：与画面无关的战斗模拟、技能、碰撞和胜负结算。
- `src/main.js`：输入、场景切换、UI、音效反馈和主循环。
- `data/units.json`：单位数值与技能数据源。
- `data/levels.json`：关卡预算、敌方编队和提示。
- `assets/units-handdrawn-atlas.png`：4 × 4 手绘角色图集；索引说明见 `assets/ASSET_NOTES.md`。
- `scripts/check-data.mjs`：无依赖数据与语法检查。
- `PLAY_GAME.cmd`：Windows 双击启动入口。
- `scripts/launch.mjs`：启动服务器、等待端口就绪并打开浏览器。

这是原型阶段的可玩切片，尚未包含存档、联网、正式美术和商用音频。
